The Candle Desk

A crypto news show run entirely by an original animated cast. No host on camera: four characters split every story into hype, doubt and on-chain proof, so each 30-second brief feels like a debate instead of a headline read.

The cast

Episode format

  1. 0–2sHook. Ledger states the biggest number of the day in giant captions. Nothing else on screen.
  2. 2–12sBull vs. bear. Bruno gives the bullish read, Ursa cuts in with the catch. One stat card each.
  3. 12–20sWhale watch. Moby whispers one on-chain move: big wallet buys, unlocks, exchange outflows.
  4. 20–27sWildcard. The viral or weird story of the day: a launch, a hack, a meme coin.
  5. 27–30sSign-off. Whole cast on screen, follow prompt, "Not financial advice" on the frame.

Production pipeline

  1. Pull the headlinesEach morning, gather 3–4 stories with sources. This can run as a scheduled task that drops the day's script into your inbox.
  2. Script in characterSplit each story between the cast using the format above. Keep every line under 12 words so captions stay readable.
  3. Voice itGive each character a distinct text-to-speech voice and keep it fixed. Consistent voices are what make a faceless cast feel real.
  4. Render 1080×1920Today: screen-record this player. Next step: move the scenes into Remotion so each script renders to MP4 automatically.
  5. Post and cross-postSame master file to all three, with platform-specific titles and covers. Always cite the source and keep "Not financial advice" on screen.
